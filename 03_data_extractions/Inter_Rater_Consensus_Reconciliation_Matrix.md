## 2. COHEN'S KAPPA ($\kappa$) FORMAL CALCULATION REPORT

* **Chance Agreement ($P_e$)**: $0.672$
* **Cohen's Kappa Formula**: $\kappa = \frac{P_o - P_e}{1 - P_e} = \frac{0.964 - 0.672}{1 - 0.672} = 0.8902$
* **Interpretation**: $\kappa = 0.89$ falls within the **High Agreement / Almost Perfect** range ($0.81 \text{--} 1.00$).
