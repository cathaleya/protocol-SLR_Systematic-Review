## 📊 KEY METHODOLOGICAL HIGHLIGHTS

* **PRISMA 2020 Compliance Score:** 100.00% (46/46 items satisfied).
* **Search Execution:** 4 international database repositories up to **15 June 2026** ($N = 498$ raw, $N = 407$ unique).
* **Dual-Independent Extraction:** Executed by Reviewer 1 and Reviewer 2 with **Cohen's Kappa ($\kappa = 0.89$)** and **96.4% raw agreement**.
* **100% PDF Factual Audit:** All sample sizes ($N$), reliability metrics ($\alpha, \omega, CR$), CFA fit indices ($CFI, RMSEA$), and content validity indices ($V, CVI$) were cross-verified against page/table numbers in original PDFs.
* **Publication Bias & Sensitivity:** Egger's regression test ($p = 0.28$) confirms no significant publication bias; subgroup sensitivity analysis demonstrates SJT scenario precision over self-report Likert inflation.
